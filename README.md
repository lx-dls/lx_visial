# LX Visual — сайт

## Публикация на GitHub Pages
1. Создай репозиторий `lx-visual`.
2. Загрузи index.html, style.css, script.js.
3. Settings → Pages → Source: Deploy from branch → main → /root.
4. Через минуту сайт будет на https://<твой-ник>.github.io/lx-visual/

## Локальный запуск
Просто открой index.html в браузере.
